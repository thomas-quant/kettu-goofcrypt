# Requirements: GoofCrypt (mobile) — native-speed Argon2id milestone

**Defined:** 2026-05-30
**Core Value:** Byte-exact interop with GoofCord/stegcloak-rs is non-negotiable; kill the first-encrypt freeze without ever sacrificing it.

> Research verdict (`.planning/research/SUMMARY.md`): byte-compatible **native** Argon2 is almost certainly unreachable in the Hermes/Kettu sandbox (libsodium's public `crypto_pwhash` hardcodes a 16-byte salt; the channelId salt is ~18–19 bytes; no WASM on Hermes; DAVE/MLS has no Argon2). The milestone is therefore **spike → gate → fallbacks**, with the on-device native path treated as a verified-or-rejected conditional branch.

## v1 Requirements

### Spike & De-risking

- [ ] **SPIKE-01**: A reusable on-device native-crypto probe enumerates the reachable native surface (`nativeModuleProxy`, TurboModules incl. DAVE/MLS/Sodium/Aes, `metro.findByProps` for `crypto_pwhash`/`argon2id`/`scrypt`, `crypto.subtle`), **persists** the result, and surfaces it via `__goofcrypt.diag()` and `/encrypt status` (the current `diagnose2.txt` probe records nothing)
- [ ] **SPIKE-02**: For any reachable Argon2 candidate, an on-device test confirms whether it accepts a real ~19-byte channelId salt **and** returns a raw 32-byte key (not a PHC string)
- [ ] **SPIKE-03**: The first-encrypt freeze is diagnosed with evidence — instrument yield-count, runtime-assert noble's `nextTick` is the macrotask form, audit for any synchronous `deriveKey` reaching a Discord-thread path, and check the `LOAD_MESSAGES_SUCCESS` concurrency storm
- [ ] **SPIKE-04**: A written native-feasibility verdict (GREEN/RED) is recorded in planning and gates whether the conditional native phase runs

### Verification Gate

- [ ] **GATE-01**: A fixed KDF test vector — `(password, real-length channelId) → expected 32-byte key` — is committed, generated by the trusted `@noble/hashes`/desktop path and cross-checked against the stegcloak-rs WASM in the harness
- [ ] **GATE-02**: The CI harness asserts the KDF vector, so byte-compatibility is testable off-device
- [ ] **GATE-03**: An on-load byte-equality self-check gate exists; any candidate derivation path must reproduce the vector before it may produce real keys, behind a `verified` flag that injection forcibly resets (structurally unbypassable)
- [ ] **GATE-04**: Path quarantine — no unverified derivation path may write to the key cache; engine selection gates strictly on `verified`, falling through to the noble JS path otherwise

### Freeze Fix & Responsiveness

- [ ] **PERF-01**: No synchronous Argon2 derivation ever runs on a Discord-thread code path — first-encrypt no longer freezes the UI
- [ ] **PERF-02**: The diagnosed fix from SPIKE-03 is applied (e.g. finer `asyncTick`, serialized cold-channel derivations, noble pinned exactly to protect the macrotask-yield patch)
- [ ] **PERF-03**: Non-blocking "deriving… / send again" feedback on the cold path — never a blocking spinner
- [ ] **PERF-04**: Proactive warming derives keys on channel switch and after Settings "Save", so the key is usually ready before the user sends

### Key-sync Fallback

- [ ] **SYNC-01**: Seamless key-sync import — clipboard auto-detect of a `goofcrypt:`-prefixed bundle offers one-tap import (no manual `/encrypt import` paste required)
- [ ] **SYNC-02**: Bundle-shape validation on import — malformed bundles (bad base64, wrong nesting) are rejected before writing, instead of silently poisoning the key cache
- [ ] **SYNC-03**: The `base64.ts` non-ASCII bounds bug is fixed (non-ASCII chars in a pasted bundle no longer corrupt decoding silently)
- [ ] **SYNC-04**: A key-sync round-trip harness test pins the `passwordId`/base64/sha256 determinism contract between `tools/derive-keys.mjs` and the plugin

### Observability

- [ ] **OBS-01**: `/encrypt status` reports the live derivation path (`native(verified)` | `js` | `imported`) and the active RNG source — fallbacks are always loud, never silent
- [ ] **OBS-02**: `/encrypt bench` measures each available derivation path using the real params (m=65536, t=3, p=1), including first-yield / longest-block latency

### Compatibility

- [ ] **COMPAT-01**: The CI byte-compatibility harness stays green across every change — GoofCord interop is preserved

### Conditional — Native fast-path (only if SPIKE-04 verdict is GREEN)

- [ ] **NATIVE-01**: A native Argon2 adapter is wired by dependency injection — the discord layer (`nativeProbe.ts`) injects a plain function into a pure crypto-layer registry (`nativeArgon.ts`); no layering violation
- [ ] **NATIVE-02**: `deriveKeyAsync` uses the native engine **iff** it passed GATE-03 on-device, with try/catch fall-through to noble; an unverified native key is never persisted

## v2 Requirements

### Frictionless key-sync (deferred — uncertain platform dependencies)

- **SYNC-05**: QR-based key-sync (desktop renders a QR, mobile scans) — depends on a reachable camera/QR module
- **SYNC-06**: Deep-link import (`goofcrypt://import?b=<bundle>`) — depends on Kettu URL-handler support

### Native (if SPIKE verdict is RED)

- **NATIVE-03**: Re-evaluate native derivation if/when a future Discord build exposes an arbitrary-salt raw Argon2 entry point — parked until the platform changes

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Changing the KDF algorithm or params | Breaks GoofCord byte-compat (GoofCord is fixed/third-party) |
| v2 wire format / migration to a 16-byte salt | Breaks interop with every existing GoofCord message — the core value forbids it |
| Server-side / remote key derivation | Defeats the privacy model and the fully-static, no-server constraint |
| Bundling a native module or WASM Argon2 | Kettu can't ship native code; Hermes has no WebAssembly |
| Raw-password-as-key (no KDF) | Trivial offline password guessing — silently weakens security |
| Silent degraded fallback | Hides which crypto path is live; makes freeze/interop bugs undiagnosable |
| Blocking "please wait 10s" spinner on send | Still freezes the user at the worst moment; the goal is *no freeze* |
| General CONCERNS.md tech-debt not on the perf path | Tracked separately (e.g. `decryptedIds` pruning, duplicate `showToast`) |
